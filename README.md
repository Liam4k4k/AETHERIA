# AETHERIA Roadmap

## Mise en ligne sur GitHub Pages

1. Crée un dépôt GitHub, par exemple `aetheria-roadmap`.
2. Ajoute `index.html`, `style.css` et `script.js` à la racine.
3. Va dans **Settings → Pages**.
4. Dans **Build and deployment**, choisis **Deploy from a branch**.
5. Sélectionne `main` et le dossier `/root`.
6. Enregistre : GitHub fournira l’URL du site.

Le site ne contient aucun login et les filtres de roadmap fonctionnent en JavaScript.
