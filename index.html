Questions fréquentes

Avant le décollage

Le serveur est-il déjà ouvert ?

Le projet entre en phase de préparation. La date d’ouverture, l’adresse et la compatibilité client seront annoncées après les premiers tests.

Sur quelle version pourra-t-on jouer ?

Le serveur vise Minecraft Java 1.21.11. La compatibilité avec d’autres versions Java reste à tester. Bedrock n’est pas prévu au lancement.

Comment soutenir Aetheria ?

La boutique n’est pas encore ouverte. Le modèle envisagé privilégie des cosmétiques affichés et achetés directement, sans avantage de jeu.

Comment participer à la préparation ?

Rejoignez la communauté depuis le bouton ci-dessous pour suivre les annonces et partager vos retours.
